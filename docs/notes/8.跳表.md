## 一、跳表引擎

### 跳表是什么？

多层链表，高层是稀疏的"快速通道"，底层是完整链表。查找时从最高层开始走，走不动了降一层。

```
Level 3: head ──────────────────→ 30
Level 2: head ──→ 10 ──→ 30 ──→ 50
Level 1: head ──→ 10 ──→ 20 ──→ 30 ──→ 40 ──→ 50
Level 0: head ──→ 10 ──→ 20 ──→ 30 ──→ 40 ──→ 50 ──→ 60
```

查 40：从 Level 3 走到 30 发现超了 → 降到 Level 2 → 走到 30 超了 → 降到 Level 1 → 找到 40。**不用旋转，不用变色。**

### 头文件声明

```cpp
#define SL_MAX_LEVEL 32

struct SkipNode {
    char *key;
    char *value;
    int level;
    SkipNode **forward;   // forward[0] 是第0层后继，forward[1] 是第1层...
};

struct SkipList {
    SkipNode *head;
    int level;
    int count;
};

extern SkipList g_sl;
```

### 完整实现 `kvstore_skiplist.cpp`

```cpp
#include "kvstore.hpp"
#include <cstdlib>

SkipList g_sl;

static int sl_random_level() {
    int level = 1;
    while (level < SL_MAX_LEVEL && (rand() % 2 == 0)) {
        level++;
    }
    return level;
}

static SkipNode *sl_create_node(int level, const char *key, const char *value) {
    SkipNode *node = new SkipNode;
    node->level = level;
    node->key = new char[strlen(key) + 1]();
    node->value = new char[strlen(value) + 1]();
    strcpy(node->key, key);
    strcpy(node->value, value);
    node->forward = new SkipNode *[level]();
    return node;
}

static SkipNode *sl_search(SkipList *sl, const char *key) {
    SkipNode *p = sl->head;
    for (int i = sl->level - 1; i >= 0; i--) {
        while (p->forward[i] && strcmp(p->forward[i]->key, key) < 0) {
            p = p->forward[i];
        }
    }
    p = p->forward[0];
    if (p && strcmp(p->key, key) == 0) return p;
    return nullptr;
}

int kvstore_skiplist_create(SkipList *sl) {
    if (!sl) return -1;
    sl->head = sl_create_node(SL_MAX_LEVEL, "", "");
    sl->level = 1;
    sl->count = 0;
    return 0;
}

void kvstore_skiplist_destroy(SkipList *sl) {
    if (!sl || !sl->head) return;
    SkipNode *p = sl->head->forward[0];
    while (p) {
        SkipNode *next = p->forward[0];
        delete[] p->key;
        delete[] p->value;
        delete[] p->forward;
        delete p;
        p = next;
    }
    delete[] sl->head->key;
    delete[] sl->head->value;
    delete[] sl->head->forward;
    delete sl->head;
    sl->head = nullptr;
    sl->count = 0;
}

int kvs_skiplist_set(SkipList *sl, const char *key, const char *value) {
    SkipNode *exist = sl_search(sl, key);
    if (exist) {
        delete[] exist->value;
        exist->value = new char[strlen(value) + 1]();
        strcpy(exist->value, value);
        return 0;
    }

    SkipNode *update[SL_MAX_LEVEL];
    SkipNode *p = sl->head;
    for (int i = sl->level - 1; i >= 0; i--) {
        while (p->forward[i] && strcmp(p->forward[i]->key, key) < 0) {
            p = p->forward[i];
        }
        update[i] = p;
    }

    int new_level = sl_random_level();
    for (int i = sl->level; i < new_level; i++) {
        update[i] = sl->head;
    }

    SkipNode *node = sl_create_node(new_level, key, value);
    for (int i = 0; i < new_level; i++) {
        node->forward[i] = update[i]->forward[i];
        update[i]->forward[i] = node;
    }

    if (new_level > sl->level) sl->level = new_level;
    sl->count++;
    return 0;
}

const char *kvs_skiplist_get(SkipList *sl, const char *key) {
    SkipNode *node = sl_search(sl, key);
    return node ? node->value : nullptr;
}

int kvs_skiplist_delete(SkipList *sl, const char *key) {
    SkipNode *update[SL_MAX_LEVEL];
    SkipNode *p = sl->head;
    for (int i = sl->level - 1; i >= 0; i--) {
        while (p->forward[i] && strcmp(p->forward[i]->key, key) < 0) {
            p = p->forward[i];
        }
        update[i] = p;
    }
    SkipNode *target = p->forward[0];
    if (!target || strcmp(target->key, key) != 0) return sl->count;

    for (int i = 0; i < sl->level; i++) {
        if (update[i]->forward[i] == target) {
            update[i]->forward[i] = target->forward[i];
        }
    }
    delete[] target->key;
    delete[] target->value;
    delete[] target->forward;
    delete target;
    sl->count--;

    while (sl->level > 1 && !sl->head->forward[sl->level - 1]) {
        sl->level--;
    }
    return 0;
}

int kvs_skiplist_modify(SkipList *sl, const char *key, const char *value) {
    SkipNode *node = sl_search(sl, key);
    if (!node) return sl->count;
    delete[] node->value;
    node->value = new char[strlen(value) + 1]();
    strcpy(node->value, value);
    return 0;
}

int kvs_skiplist_count(SkipList *sl) {
    return sl ? sl->count : -1;
}
```

### 知识点

**forward 数组：** 一个节点在多层链表中出现，每层都有一个后继指针。`forward[i]` 就是第 i 层上的后继。

**随机层数：** 每层 50% 概率升一层，让高层节点稀疏、底层节点完整。这是跳表的概率平衡——不用旋转，靠随机。

### 和红黑树对比

| | 红黑树 | 跳表 |
|---|---|---|
| 插入后修复 | insert_fixup（旋转变色） | 不用修复 |
| 删除后修复 | delete_fixup（4 case） | 改指针就行 |
| 需要理解 | 旋转变色、黑高平衡 | 链表+随机层数 |
| 代码量 | ~300 行 | ~120 行 |

### 面试要点

Redis 的 ZSet 底层就是跳表（不是红黑树）。为什么用跳表：
1. 范围查询更简单（底层链表顺序遍历）
2. 实现简单，容易调试
3. 可以通过调整层数概率平衡性能和内存

## 二、CMake 构建管理

### 为什么用 CMake 不用 Makefile？

| | Makefile | CMake |
|---|---|---|
| 跨平台 | 差（Linux only） | 好（自动生成 VS 工程） |
| 写规则 | 手写 `.c→.o` 规则 | `add_executable` 一行 |
| 找库 | 手写 `-I -L -l` | `find_package` 自动找 |
| IDE 支持 | 手动配 | VS Code/CLion 自动识别 |
| 面试要求 | 很少要求手写 | 基本都要求会 |

项目虽小，但 CMake 是现代 C++ 标配，简历加分。

### CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.10)
project(kvstore CXX)

set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_compile_options(-fpermissive -Wno-builtin-macro-redefined)

include_directories(${CMAKE_SOURCE_DIR}/NtyCo/core)
link_directories(${CMAKE_SOURCE_DIR}/NtyCo)

set(CMAKE_BUILD_RPATH "${CMAKE_SOURCE_DIR}/NtyCo")

add_executable(kvstore
    kvstore.cpp
    kvstore_mp.cpp
    kvstore_array.cpp
    kvstore_hash.cpp
    kvstore_rbtree.cpp
    kvstore_skiplist.cpp
    ntyco_entry.cpp
)

target_link_libraries(kvstore ntyco)

add_executable(testcase testcase.cpp)
```

### 常用命令

```bash
mkdir -p build && cd build
cmake ..          # 生成 Makefile
make              # 编译链接
./kvstore         # 运行
```

改了代码后只跑 `make`，不用重新 `cmake ..`。只有改了 `CMakeLists.txt`（加新源文件）才需要重新 `cmake ..`。

### 两个命令各干什么

- `cmake ..`：读 CMakeLists.txt，生成 Makefile
- `make`：读 Makefile，真正编译链接

### 常见 warning 处理

**`_GNU_SOURCE redefined`：** NtyCo 头文件自己又定义了一次。加 `-Wno-builtin-macro-redefined` 消除。

**`invalid conversion from void* to nty_schedule*`：** NtyCo 是 C 库，C++ 不允许 void* 隐式转换。改 NtyCo 头文件加 `(nty_schedule *)` 强转，或加 `-fpermissive`。

**动态库找不到：** `libntyco.so` 不在系统路径。用 `set(CMAKE_BUILD_RPATH ...)` 把库路径编译进可执行文件，以后不用 `export LD_LIBRARY_PATH`。
